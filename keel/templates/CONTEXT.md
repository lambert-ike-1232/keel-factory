## Why this file pays for itself

Agents dropped into a project figure out the jargon as they go, so they use twenty
words where one will do. A shared glossary fixes that, and the effect compounds:

- **Before:** "there's a problem when a lesson inside a section of a course is made
  real, meaning given a spot in the file system"
- **After:** "there's a problem with the materialization cascade"

Fewer tokens per exchange, consistent names for variables and files, easier navigation
for the next session, and less thinking spent on translation. It is the highest-return
document per line written in the whole set.
